## 📝 Content Guidelines

### Keyword Placement
- **H1:** Primary keyword (once)
- **H2s:** Secondary keywords (2-3 times)
- **Intro paragraph:** Primary keyword (once)
- **Body:** Natural keyword variations
- **FAQs:** Long-tail question keywords
- **Alt text:** Descriptive with keywords
- **Meta description:** Primary keyword (once)

### Keyword Density
- Primary keyword: 1-2% density
- Secondary keywords: 0.5-1% density
- Long-tail keywords: Natural inclusion
- **Never keyword stuff** - prioritize user experience

### Content Quality
- Minimum 1,500 words for pillar pages
- Minimum 1,000 words for blog posts
- Answer user questions comprehensively
- Include Umrah-specific context
- Use natural, conversational language
- Address pilgrim pain points
